# Genealogía García

Sitio estático del linaje García (Huachichil, Saltillo) y Gaona (Galeana, Rayón, Ciénaga del Toro) hasta Blas de la Garza Falcón.

Portada: `index.html`. Cada botón abre la ficha con el acta y la transcripción cuando el papel ya está en el expediente.

Repo: https://github.com/sefaradmx-sys/genealogia-garcia

Para publicar: Settings → Pages → Source: GitHub Actions o Deploy from branch `main` / root.
